# Данные и назначение репозитория

## Назначение репозитория

**Для кого:** студенты и начинающие разработчики, изучающие RAG.

**Что демонстрирует:**
- Полный offline-pipeline: сырые данные → документы → чанки → TF-IDF индекс → поиск → demo-ответ
- Улучшенный chunking через `RecursiveCharacterTextSplitter` (LangChain)
- Ответ только по найденным фрагментам с указанием источника (doc_id, score)
- Явный отказ, если релевантного контекста нет
- Streamlit UI с метаданными фильмов (год, режиссёр)

**Границы MVP:**
- Поиск по словам (TF-IDF), не по смыслу
- Demo-режим без внешних LLM
- ~1000 фильмов, ~3000-5000 чанков
- Учебный шаблон для повторения на своих данных

## Источники данных

| Источник | Файл в проекте | Комментарий |
|----------|----------------|-------------|
| [Wikipedia Movie Plots (Kaggle)](https://www.kaggle.com/datasets/jrobischon/wikipedia-movie-plots) | `data/raw/wiki_movie_plots_deduped.csv` | Скачивается локально. **Не коммитится** — см. `.gitignore`. |

**Лицензия:** CC0 (Wikipedia data)

**Дата выгрузки:** июнь 2026

## Что индексируем

| Поле | Индексируется? | Где используется |
|------|:--------------:|------------------|
| `text` (описание сюжета) | **Да** | TF-IDF матрица, поиск, demo-ответ |
| `name` (название фильма) | Нет (метаданные) | UI, источники |
| `doc_id` | Нет (метаданные) | UI, источники |
| `metadata.year` | Нет | UI, фильтрация |
| `metadata.director` | Нет | UI |

**Pipeline:**

**Чанки:** `RecursiveCharacterTextSplitter`, max 400 символов, overlap 50 (`app/chunker.py`).

**Поиск:** cosine similarity по TF-IDF векторам (`app/retriever.py`).

## Что не индексируем

| Не индексируется | Причина |
|------------------|---------|
| `data/raw/*.csv` | Сырой CSV — только для локальной подготовки |
| `data/processed/*.jsonl` | Промежуточные артефакты |
| `data/index/*` | Индекс пересобирается командой `build_index.py` |

## Состав демо-корпуса

~1000 фильмов (случайная выборка из 35,000+), темы — разнообразные:

| Пример | doc_id | Тема |
|--------|--------|------|
| Inception | movie_... | Сны, подсознание |
| The Shawshank Redemption | movie_... | Тюрьма, побег |
| Interstellar | movie_... | Космос, время |

**Рабочие demo-запросы в UI:**
- «Какой сюжет у фильма Inception?» → ответ с doc_id
- «Фильмы про космос» → список фильмов
- «Как приготовить борщ?» → отказ (negative-case)

## Улучшения по сравнению с оригиналом

1. **Chunking:** Заменён кастомный chunker на `RecursiveCharacterTextSplitter` из LangChain — лучшее разбиение по семантическим границам (абзацы, предложения, слова).
2. **Метаданные:** Добавлены год и режиссёр в UI и ответ.
3. **Масштаб:** 1000+ записей вместо 9.

## Как обновить данные

1. Скачать `wiki_movie_plots_deduped.csv` с Kaggle в `data/raw/`.
2. Запустить подготовку данных.
3. Пересобрать индекс: `uv run python scripts/build_index.py`
