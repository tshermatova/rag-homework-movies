# Conventions — правила для проекта

## Границы

- Реализуем **только MVP** из vision.md
- Минимальный diff: не рефакторим вне текущей задачи

## Архитектура кода

- Offline / online: индекс строит `scripts/build_index.py`; Streamlit только загружает индекс
- Один модуль — одна роль: ingest, chunking, index, retrieval, demo-answer, UI
- Конфиг в одном месте (`app/config.py`)
- Пути — через `pathlib.Path`

## RAG-поведение

- Каждый ответ содержит **источники:** doc_id, фрагмент текста, score, метаданные
- Demo-режим: ответ **только из найденных чанков**
- Retrieval возвращает **top-k** с score
- Индексируется **только текст** описаний

## Стиль

- KISS: plain functions и простые dict
- Код — на английском; комментарии — на русском
- Без «магии»: явные шаги pipeline
