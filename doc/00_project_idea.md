# Идея проекта

**Учебный RAG** на описаниях фильмов Wikipedia: локально, просто, с ответом и источниками.

## Проблема

RAG часто воспринимают как «промпт к ChatGPT», хотя это **цепочка шагов**: данные → чанки → индекс → поиск → ответ.

## Цель

Собрать учебный проект, который:
- Показывает **как пользоваться RAG** — не только что это такое
- Запускается локально
- Проходит весь pipeline от сырых данных до ответа
- Возвращает ответ **с источниками** (фильм, фрагмент, метаданные)
- Демонстрирует улучшенный chunking через `RecursiveCharacterTextSplitter`

## Для кого

Студенты и начинающие разработчики.

## Данные

**Wikipedia Movie Plots** с Kaggle:
- 35,000+ описаний фильмов
- Понятная тематика
- Есть структура (название, год, режиссёр, жанр)

## Результат MVP

Приложение (Streamlit), где можно спросить:
> «Какой сюжет у фильма Inception?»

Система находит подходящие фрагменты, формирует ответ и показывает, **из какого фильма** взята информация.
